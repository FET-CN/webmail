# FlowEcho MeowPy 社区准则

FlowEcho MeowPy 是面向 MicroPython 的公开技术社区，讨论固件、库、工具链、硬件适配和项目实践. 内容应便于后来者检索、理解、验证和复用；发布者对自己发布的内容负责. 

## 提问参考

提问前请阅读[《提问的智慧》](https://soc.ustc.edu.cn/Digital/2025/lab0/ask/). 

## 内容与版面

- 按板块和标签归类，不重复或交叉发帖，不连续顶帖或刷屏. 
- 教程和资源写明适用版本、验证结果与限制；转载注明出处，代码和资料遵守原许可证. 
- 可以使用 AI 辅助整理，但必须自行核验；不得把未经验证的生成文本、代码或结论当作个人实测经验发布. 
- 回复围绕主题；技术结论说明依据和不确定之处，需要展开新问题时另开主题. 

## 技术与政治的边界

是否属于技术讨论，不按关键词判断，而看内容的目的和必要性：

- 围绕具体工程问题，能够用代码、日志、数据、协议或复现步骤验证，且只保留解决问题所需背景的，属于技术讨论. 
- 以表达政治立场为目的，评价国家、政党、政府、政策或政治人物，或借技术话题进行讽刺、宣传和引战的，属于政治内容. 
- 例如，提到 GFW 不会自动判为政治内容. 分析 DNS 污染、TCP 重置、SNI 或 QUIC 可达性并用于排查具体问题，属于技术讨论；评价相关政策的正当性或优劣、延伸政治争论，或提供绕过限制的教程、节点和订阅，不属于本社区的技术讨论. 

## 禁止事项

- 人身攻击、歧视、骚扰、恶意引战、造谣，或公开自己或他人的隐私、账号、密码、令牌和密钥. 
- 政治宣传、政治立场表达、时政评论，以及围绕国家、政党、政府、政策或政治人物的立场性评价和争论. 必要的技术背景按上文边界处理. 
- 违法或有害内容，包括色情、暴力、赌博、毒品、诈骗和黑灰产. 
- 恶意软件、可直接用于入侵、破坏或窃取的漏洞利用代码、破解盗版或绕过付费限制的资源. 安全讨论应脱敏，若提供相关 PoC, 应按其敏感程度设置 topic 可见范围.
- 侵犯知识产权、冒充他人或管理员的内容. 
- 广告骚扰、外部引流、机器灌水、无意义内容，以及滥用评分、标签、格式和举报功能. 
- 通过拆字、编码、图片、短链或其他变体规避审核，或用小号绕过禁言、封禁. 个人资料、签名和私信同样适用本准则. 

## 推广与交易

与 MicroPython 或开源项目直接相关的推广，须按对应板块规则发布，并说明项目性质、来源、许可证、是否收费及利益关系. 不得未经请求私信广告、强行拉群、发布返利信息或为无关社区引流；不得重复刷屏. 

交易须说明商品来源、价格和风险，禁止黑灰产、侵权资源及其他违法交易. 

## 举报与管理

发现违规内容，请使用举报功能并附帖子链接、理由和必要证据，不要在原帖争吵或用灌水回应. 举报不得用于报复或骚扰. 

管理可根据情节提醒整改、移动、合并、关闭或删除内容，并对账号警告、限权、禁言或封禁；重复、恶意和严重违规从重处理，违法、诈骗或危害社区安全的行为可直接处置. 处理应说明依据并保留记录. 

对处理有异议，请私信管理提交事实和诉求，不要开帖围攻或用小号规避处理. 管理员和版主同样受本准则约束. 

准则会根据社区实践和成员反馈修订，修订内容以公告为准.
